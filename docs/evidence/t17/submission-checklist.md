# T17 submission checklist

## Repository

- [ ] Final T17 pull request merged with green CI.
- [ ] Fresh remote clone installs with `npm ci`, builds, launches, and passes all checks on
      Node.js 24.
- [ ] Browser-free record, inspect, retrieve, playback, and verification workflow passes.
- [ ] Working tree is clean and contains no recording, dependency, credential, or raw-log artifacts.

## Requirements and evidence

- [ ] Original three-page assessment independently audited by SHA-256 identity.
- [ ] Every PDF requirement and A01-A30 appears exactly once in validated traceability.
- [ ] T15 and T16 committed evidence validates without rerunning or committing the long recording.
- [ ] README includes setup, architecture, independent format/waveform details, operational
      contracts, measured results, verification output, trade-offs, limitations, and next work.
- [ ] Standards and specification reviews have no unresolved findings.

## Demonstration and handoff

- [ ] Owner-narrated 1920x1080 H.264/AAC video is five to seven minutes and fully reviewed.
- [ ] Narration, screenshots, measurements, and PASS claims match the checked application.
- [ ] Video and checksum are published under private release `t17-submission`; downloaded SHA-256
      matches `video.json`.
- [ ] Repository, release, and video links work for an authorized account.
- [ ] Owner has been reminded to grant the identified reviewer repository access.
- [ ] Issue #18 is closed only after release verification; parent #1 and optional #19 remain open.
