# Bound the public demo on one persistent host

Keep the public demonstration on one long-running Node.js instance with a directly attached
persistent volume, matching the acquisition owner's single-writer process and file model. Activate
explicit hosted limits, throttling, temporary-recording rotation, and path redaction at the HTTP
boundary; local operation remains unrestricted, while static/serverless-only hosting and a
distributed storage redesign remain rejected for this assessment follow-up.
